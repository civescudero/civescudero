## Proyecto destacado

### FIORELLA · Software de gestión comercial

Aplicación de Windows 100 % local para inventario, ventas, clientes, gastos, finanzas y reportes. Incluye comprobantes PDF y PNG con un único consecutivo, pago íntegro obligatorio, valor del domicilio como concepto separado, respaldos verificados e instalador NSIS.
